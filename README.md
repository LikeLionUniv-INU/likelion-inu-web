# LIKELION INU 🦁

멋쟁이사자처럼 인천대학교의 활동과 모집 정보를 안내하는 공식 웹사이트입니다.

## 주요 기능

- **홈:** 동아리 소개 및 모집 안내
- **파트 소개:** 기획, 디자인, 프론트엔드, 백엔드 파트 안내
- **커리큘럼:** 연간 활동 일정 확인
- **FAQ:** 자주 묻는 질문 확인
- **지원 안내:** 모집 기간에 따른 지원 페이지 연결

## 기술 스택

- **Frontend:** React, JavaScript, Create React App
- **Styling:** styled-components
- **Routing:** React Router
- **Deployment:** Vercel

## 실행 방법

```bash
npm install
npm start
```

프로덕션 빌드:

```bash
npm run build
```

## 프로젝트 구조

- `src/components` — 헤더, 푸터 등 공통 컴포넌트
- `src/pages` — 소개, 커리큘럼, 파트, FAQ, 지원 화면
- `src/styles` — 페이지별 스타일
- `src/assets` — 이미지, 아이콘, 폰트
